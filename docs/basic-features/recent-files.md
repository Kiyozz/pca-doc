# Recent files

## Description

PCA remembers the **last 30 scripts you compiled**, and keeps them between launches.

Restart PCA the next day, open Recent files, tick the scripts you were working on, load them. You are back where you left off without hunting through folders.

## How the list is filled

A script enters the list when you press **Start** — not when it succeeds. A compilation that failed is exactly the one you want to load again.

The list holds 30 scripts at most, most recent first, and each path appears only once. Past 30, the oldest drops off.

## Loading scripts

1. Open **Recent files** with the button at the top of the Compilation page.
2. Click the scripts you want. Ticked ones are loaded.
3. Press **Load**.

They are added to the compilation list, next to whatever is already in it.

Scripts already in the list are greyed out — there is nothing to load twice. If every recent script is already loaded, the dialog says so rather than showing an empty list.

## In the dialog

- **More details** shows the full path of each script, instead of its name alone. The switch is remembered.
- Each line has a **delete** button, to drop a script from the list without touching the others.
- **Right-click anywhere** in the dialog for **Select all**, **Select none**, **Invert selection** and **Clear**.

## Recent files or a group?

They solve two different problems.

| | Recent files | [Groups](groups) |
| --- | --- | --- |
| Filled | On its own, as you compile | By you |
| Contents | Your last 30 scripts, all mods mixed | The scripts you chose, named |
| Lifespan | Rolls over | Until you delete it |

Recent files is for picking up where you left off. A group is for a set of scripts you load again and again — make one as soon as you find yourself ticking the same names every morning.
